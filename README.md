Sitio estático listo para publicar con GitHub Pages.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub y sube `index.html` y la carpeta `assets`.
2. En el repositorio entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`, luego guarda.
5. Espera a que GitHub Pages publique el sitio y comparte la URL.
